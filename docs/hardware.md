# Железо и окружение (фаза 0–1)

## Устройство

- X96 Max, SoC Amlogic **S905X2** (G12A, Mali-G31), 4× Cortex-A53, 4GB RAM
- Armbian: `Linux armbian 6.18.51-ophub #1 SMP PREEMPT_DYNAMIC Mon Sep 14 02:05:42 UTC 2026`
- `BOARD="S905x2"`, `BOARD_FAMILY="meson-g12a"`, `LINUXFAMILY="amlogic"`
- Загрузчик: mainline u-boot (armbian), env разобран; dual-boot-план: флаг в env → SD (Armbian) / eMMC (Android)

## Диски (важно)

| Диск | Назначение | Правило |
|---|---|---|
| eMMC | Android (оригинал) | **НЕ трогать** — dmesg сыплет `mmc_erase/BKOPS`, только наблюдать |
| SD | Загрузка Armbian | основной носитель загрузчика |
| USB HDD | корень + данные (фаза 2) | ещё не подключён |
| NVMe «Lenovo» (Disk 0) | чужой диск на Thinkpad | **НЕ трогать** |

## Вывод / дисплей

- Режим HDMI: **1920×1080** (fb0 1920×1080)
- Монитор ViewSonic VX2433wm: есть **сдвиг картинки** (артефакт вывода) — диагностирован, отложен пользователем
- Сырой вывод в `/dev/fb0` ограничен ~16.5 МБ (2 кадра) — для видео непригоден; показ идёт через mpv (DRM)
- Измеренная частота обновления mpv ≈ **49 Гц** (не 60) — mpv это учитывает (`display-resample`)

## Сеть / периферия

- Ethernet: up (100Mbps, RTL8211F)
- WiFi: подключено (учётные данные здесь не хранятся)
- BT: BCM4356A2 probed
- Звук: подтверждён
- ИК-пульт: подтверждён (кнопки), полная настройка — планы
- SSH: root@192.168.3.243 (пароль локально, в репо не входит)

## Особенности

- `/tmp` = tmpfs (сбрасывается при ребуте) — важное держать в `/root`
- Кольцевой буфер dmesg маленький: спам H.264-цикла (~100 строк/сек) вытесняет старые записи — логи собирать сразу
- Поведение watchdog: зависание драйвера может вызвать **автоперезагрузку** (наблюдалось во время тестов с альтернативной прошивкой)
